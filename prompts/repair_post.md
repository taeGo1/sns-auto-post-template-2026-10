# 直す（消す前に直す）— 2026-10-04 追加

機械の照合（check_evidence.py）の報告を読み、**合わない行を「消す」のではなく「直す」**。
深さを保ったまま、根拠の無い文だけを無くすのがこの段の役目（直すたびに文章が薄くならないように）。

## 読むファイル
- `sns-posts.json`：投稿案（自分が書いたもの）
- `evidence-check.json`：機械の照合の報告（この回は削除していない。報告だけ）
  - `evidence_failed`：根拠の原文が材料に見つからない／Fixed 行を「できること」の根拠にしている／原文に無い数・限定の言い切り
  - `unsupported_tokens`：材料にも根拠にも無い名前・数字・コマンド
  - `removed_lines`：**このあと削除される予定の行**と理由（「根拠が付いていない事実の行」「一言が体験の形」など）
  - `warnings`：削除はされないが直すべきこと。例「報道だけの話題なのに『（〇〇によると）』の出どころの行が無い」→ 根拠の `source` の媒体名で「（〇〇によると）」の行を、その事実の直前か直後に1行足す（2026-10-05 昼の試しで抜けた）
- `sns-context.json`：材料（`primary_evidence` の `lines`＝更新履歴、`text`＝公式ドキュメント、`ai_sources`、記事の title・summary）
- `prompts/generate_post.md` の「話題の選び方と根拠の付け方」「伸びている投稿の書き方」の節（決まりは同じ）

## まず `removed_lines`（削除予定の行）を**1行残らず**処理する
- `evidence-check-report.json` の `removed_lines` に載っている行は、このあと**全部削除される**。1行ずつ、下の 1〜5 のどれかを必ず行う（限定の言い切りだけ直して終わらない）
- 多くは「材料（公式ドキュメント）を日本語に言い換えた文に、evidence を付け忘れた」もの。**対応する原文を材料から探して evidence に足す**（quote は原文そのまま）。これがいちばん多い直し
- 見出しの行（「・エージェントビュー」「① 画面を追加する」）は、そのままで残る（名前だけの行は削除されない）。中身の行だけ直す
- 全部処理し終わるまで終了しない。処理した数を repair-log.json に書く

## 直し方（行ごとに、この順で考える）
1. **根拠を付け直す**：中身は原文にあるのに、evidence に入れていなかった／`sentence` が投稿の文と一字一句同じでなかった／`quote` が原文と少し違っていた（`**`・バッククォート・表の「|」は照合で無視されるので、それ以外のずれ）→ 正しい `sentence`・`quote` を evidence に足す・直す。**文はそのまま残る**
2. **原文どおりに書き直す**：言いすぎ（「だけ」「1つ」「自動で」など原文に無い限定）、仮の名前（`/コマンド名`）、意味のずれ → 原文の範囲に収まる言い方に直し、evidence も直す。例：「伝えるだけ」→「伝えると Claude が書く」
3. **一言として登録する**：読む人への問いかけ・素の反応・お願いが `voice_lines` に入っていなかった → `voice_lines` に足す（最後の1〜3行の中にあるものだけ。体験・使用感の形は不可）
4. **見出しは「〇〇：」の形に**（「Mods でできること。」→「Mods でできること：」）
5. **どうしても根拠が見つからない行だけ消す**。消したら前後のつなぎ（「つまり、」「👇」）を最小限に整える

## してはいけないこと
- 新しい事実を足さない（材料に無いことは書かない）
- 「迷ったら残す」はしない。根拠を付けられない事実の文は残さない（この段のあと、機械の照合がもう一度動き、根拠の無い行は削除される）
- 口調・構成・長さを変えない（直す行だけ触る）
- `post_text` の改行・箇条書きの印（「・」）はそのまま

## 出力の量
- 直す行だけ **Edit** で直す（sns-posts.json 全体を Write で書き直さない）。分析や経過を文章で書き出さない。報告は1行

## 出力
- `sns-posts.json` を上書き（直した投稿案。形式は元と同じ）。**直すところが無くても `repair-log.json` は必ず書く**（`fixes: []`）
- 直した内容を `repair-log.json` に保存：
```json
[{"post": 1, "fixes": ["根拠を付け直し：〇〇（quote: …）", "書き直し：『伝えるだけ』→『伝えると Claude が書く』", "voice_lines に追加：…", "削除：…（根拠なし）"]}, {"post": 2, "fixes": []}]
```
完了したら、各投稿の「直した行数・消した行数・文字数」を1行で報告する。
