# 本当に試す計画

`context.chosen_topic` の話題を、クラウドで Claude Code に本当に使わせて見せるための計画を立てます。
その記録が、投稿の「試してみると」と、作業動画の根拠になります。

## 読む人
**`prompts/reader.md` を Read する**（読む人・使い方の深さはそこに書いてある）。

## ここは変えない（仕組みが動くために必要）

### 話題
- `context.chosen_topic.topic` をそのまま使う（ここで選び直さない）。無いときだけ `hot_topics` の先頭

### 試すかどうか
- **試すのは、話題が Claude・Claude Code の機能で、その機能そのもの（または公式に書いてある頼み方）を Claude Code で動かせるときだけ**
- 他社の発表・やって見せられない話題は `"doable": false`（その日はパターン動画になる）。別の作業をこじつけて混ぜない
- 機能の使い方は `primary_evidence`（公式の本文）から。公式に無い機能名・数字・状態名を足さない

### 作業の条件
- 架空のサンプルデータ・5分以内・ネット不要。結果は人が見て分かるファイル（一覧・文章・比較表）
- 頼み方（task）に、プログラムの言葉（CSV・JSON・関数・スクリプト）を入れない。技術の条件は `hidden_rules` に
- 現実の効果に見える数字（「70%削減」など）が出る作業は選ばない

### 出力（`work-plan.json` に Write する。JSON だけ）
```json
{
  "topic": "話題（chosen_topic.topic をそのまま）",
  "can_do": "この機能で読む人ができるようになること（1〜2行）",
  "ideas": ["使い方の候補1：誰が・どんな仕事で・どう頼むか", "候補2"],
  "demo": {
    "doable": true,
    "reason": "この作業を選んだ理由（1行）",
    "feature": "使った機能（30字まで・正直に）",
    "scene": "読む人のどんな仕事の場面か",
    "watch": "動画で見えるはずの動き（→ でつなぐ）",
    "title": "~/demo-xxx（英小文字とハイフン）",
    "task": "普通の言葉の頼みごと・2文以内（動画にそのまま映る）",
    "hidden_rules": "技術の条件（動画には映らない）",
    "tools": [],
    "model": "sonnet",
    "max_minutes": 5,
    "files": { "brief.txt": "ファイルの中身（架空のサンプル）" },
    "result_file": "一覧.md"
  }
}
```
- 値は**形の見本**。その日の機能に合う値にする。担当分け（サブエージェント）の機能の日だけ `"tools": ["Agent"]`
- 試さない日は `{"topic": "…", "can_do": "…", "ideas": [...], "demo": {"doable": false, "reason": "理由"}}`
- 完了したら「作業：〇〇（doable=true/false）」と1行で報告する。分析や経過は書き出さない
