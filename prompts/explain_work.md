# 作業動画の「説明文字」（本当に試したあとに1回だけ）— 2026-10-05

クラウドで Claude Code に本当に作業をさせた記録（replay.json）を読み、**動画の場面ごとに、普通の人向けの短い説明**を書く。
動きを見せて、それを説明する文字を入れる。読む人はエンジニアではない（`prompts/reader.md`）。

## 読むファイル
- 作業記録の要約 `replay-brief.json`（場所は起動時の指示。**これだけ読む。replay.json は台本入りで大きいので読まない**）：`prompt`（頼んだ言葉）・`blocks`（本流の動き。`block` が番号）・`lanes`（担当ごとの動き）・`compare`（2通り比べたときの2回目：a_seconds・b_seconds）・`resultFile`・`resultPreview`・`realSeconds`
- 計画 `work-plan.json`：`demo.watch`（見えるはずの動き）・`demo.feature`・`demo.scene`

## 書き方
- 説明は **記録に実際にある出来事だけ**。「3つの担当が同時に動き始めた」「文章担当が先に終わった」「ここで誤字を1か所直している」「2回目は1人で順番にやっている」「一覧が1つにまとまった」
- 1つ **22字まで**。**8つまで**。普通の言葉で（セッション→担当／ツール→道具／ファイル名はそのままでよい）
- `block` は、その説明を出す場面＝本流の `blocks` の番号（0 から）。担当の中の出来事は、その担当を起動した Agent の block の番号
- **数字と英字の言葉は、記録にあるものだけ**（機械が照合して、無いものは落とす）。感想・評価（すごい・便利）は書かない。読む人が「いま何が起きているか」を分かるための字
- `feature`：使った機能の名前（30字まで）。計画の demo.feature を記録と照らして、本当に使った機能を書く（使っていない機能を書かない）
- 2通り比べた記録（compare）があれば `verdict`：記録の数字で言える違いを1行（22字まで。例「3人同時の方が40秒早かった」）。言えなければ書かない

## 出力（`notes.json` に Write する。JSON だけ）
```json
{
  "feature": "サブエージェント（担当分け）",
  "notes": [
    { "block": 0, "text": "まずブリーフを読む" },
    { "block": 2, "text": "3つの担当が同時に動き出す" },
    { "block": 5, "text": "最後に1つの一覧にまとめる" }
  ],
  "verdict": "3人同時の方が40秒早かった"
}
```
完了したら「説明：〇件」と1行で報告する。
