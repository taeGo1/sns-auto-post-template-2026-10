# SNS 自動投稿テンプレート（2026年10月版）

AI が、
**① あなたの「読む人」に合わせて話題を集める → ② 気になる話題を1つ選ぶ → ③ その機能を本当に試す → ④ 事実を確かめながら X の投稿を書く → ⑤ 同じ話題で動画とカルーセルを作る**
ところまでを、GitHub の上で自動で進めます。できたものは **Google ドライブ** に入り、**メール** でお知らせが届きます。

- Claude は、**あなたの Claude のプラン（Pro・Max）の中**で動きます（追加の料金はかかりません）
  - 使うモデルは `settings.yml` の `claude` で選べます。最初は **Sonnet**（Pro・Max どちらでも使える）。**Max プランの人は、話題を選ぶ段（`model_choose`）を `opus` に変えると、選ぶ話題の精度が上がります**
  - 1回動かすと、Claude をそれなりに使います。ふだんの Claude の使用量と同じ枠を分け合うので、Pro プランの人は特に、使用量の残りを見ながら動かしてください
- GitHub（非公開リポジトリ）は、GitHub の無料枠の中で動きます
- Google ドライブへの保存とメールは、あなたの Google アカウントの Apps Script（無料）が行います

---

## 何が届くか（1回動かすと）

| 届くもの | 中身 | どこに |
|---|---|---|
| X の投稿案 | 2本（投稿1＝その日の話題、投稿2＝別の話題） | メール・ドライブ |
| Instagram・Threads・TikTok の文章 | 投稿1と同じ話題で各1つ | メール・ドライブ |
| 動画 | 横長（X・Threads 用）と縦長（リール・TikTok 用） | ドライブ |
| カルーセルの画像 | 4〜8枚 | ドライブ |

ドライブの場所：**マイドライブ ＞ SNS自動投稿 ＞ 日付_テーマ**
※ 話題が Claude の機能で、実際に試せる日は「作業動画」（Claude Code が本当に動いた記録の動画）になります。試せない日は「パターン動画」（8種類の型の動画）になります。
※ 投稿はしません。届いたものを確認して、自分で投稿します。

## ステップ1：このテンプレートを自分の場所に複製する

1. このページの右上の緑のボタン **「Use this template」** →「**Create a new repository**」
2. **Repository name**：好きな名前（例：`my-sns-auto`）
3. **Private** を選ぶ（あなたの発信の設定が入るので、公開しないでください）
4. **Create repository**

---

## ステップ2：Claude の鍵を GitHub に入れる（`CLAUDE_CODE_OAUTH_TOKEN`）

Claude のプランの中で動かすための鍵です。**1回だけ**、自分の Mac の「ターミナル」アプリで取ります（いちばん安全な方法です。鍵がほかのアプリを通りません）。

1. **ターミナル**アプリを開く（Finder → アプリケーション → ユーティリティ → ターミナル。または Spotlight で「ターミナル」と検索）
   - Windows の人は「PowerShell」を開く
   - 先に Claude Code が入っている必要があります（入っていなければ、講座で案内する入れ方で入れてください）
2. 次の1行を打って Enter
   ```
   claude setup-token
   ```
3. ブラウザが開くので「許可」
4. ターミナルに `sk-ant-oat` で始まる長い文字が出るので、それをコピー（あとで見られないので、この画面のうちに）
5. GitHub の自分のリポジトリ → **Settings** → 左の **Secrets and variables** → **Actions** → 緑の **New repository secret**
   - Name：`CLAUDE_CODE_OAUTH_TOKEN`
   - Secret：コピーした文字 → **Add secret**

> この鍵は、取った人の Claude のプランを使える「合い鍵」です。
> **チャット（Claude を含む）に貼らない・スクリーンショットに撮らない・人に渡さない**。GitHub の Secrets にだけ貼ってください。貼り終えたらターミナルは閉じてOKです。

## ステップ3：受け取り係（Google ドライブとメール）をつくる

できたものを Google ドライブに入れて、メールで知らせる係です。Google Apps Script で作ります（無料）。

1. https://script.google.com を開く →「**新しいプロジェクト**」
2. 中に最初からある文字を全部消して、このリポジトリの **`gas/受け取り係.gs`** の中身を全部コピーして貼り付け →「保存」（💾）
3. 上の関数の選びで「**はじめに1回だけ実行**」を選んで「**実行**」
   - 「承認が必要です」→ 自分のアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - 下の「実行ログ」に **「GAS_KEY に入れる値：〇〇〇〇」** と出るので、〇〇〇〇 をコピー
4. 右上の「**デプロイ**」→「**新しいデプロイ**」→ 歯車から種類「**ウェブアプリ**」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 出てきた **ウェブアプリの URL** をコピー
5. GitHub の Secrets（ステップ2と同じ場所）に2つ入れる
   - Name：`GAS_URL` ／ Secret：ウェブアプリの URL
   - Name：`GAS_KEY` ／ Secret：3でコピーした値

> 「アクセスできるユーザー：全員」でも、鍵（GAS_KEY）を知らない人は何もできません。

## ステップ4：手で1回動かす

1. 自分のリポジトリの上のタブ **Actions** を開く（案内が出たら、緑のボタンで有効にする）
2. 左の一覧から「**SNS の投稿案と動画を作る**」→ 右の「**Run workflow**」→ 緑の「**Run workflow**」
3. 黄色い丸（動いている）→ 緑の ✓ で完了。**約〇〇分**（※講座で実測した時間を書く）

### 結果がどこに届くか
- **メール**：件名「【SNS自動生成】今日の投稿案と動画：〇〇」。X の投稿案2本と、各 SNS の文章、ドライブのリンク
- **Google ドライブ**：マイドライブ ＞ SNS自動投稿 ＞ 日付_テーマ（動画・カルーセルの画像・届いた内容.txt）

> 最初は、決まりのファイルが空のまま動かしてOKです。「空のまま1回動かして、出てきたものを見る」→ 自分用に書き換える → もう一度動かす、の順で進めます。
> 空のままだと、話題は幅広いアプリ・サービスの新機能から選ばれます。`prompts/reader.md`（読む人）を書くと、あなたの読む人に合わせた話題を集めるようになります。

## ステップ5：決まりのファイルを自分用に書き換える

AI はこのファイルを読んで動きます。**各ファイルのいちばん上に「Claude への頼み方」が書いてあります。** それをコピーして Claude に送ると、質問されながら中身が埋まります。

Claude でこのリポジトリを開く方法：Claude のデスクトップアプリの「Code」タブ、または claude.ai/code で、このリポジトリを選んで開く。

| 順番 | ファイル | 何を書くか |
|---|---|---|
| 1 | `prompts/reader.md` | 読む人（誰に向けて・何を見たいか・何が弱いか・使い方の深さ）。**話題を集める先も、ほかのファイルも、すべてここを読む** |
| 2 | `examples/` ＋ `tonmana.md` | いいなと思う投稿を `examples/` に集め（本数は自由）、Claude に共通する書き方を分析させて `tonmana.md` にまとめる。**真似るのは書き方だけ。中の事実は使わない** |
| 3 | `prompts/choose_topic.md` | 話題を選ぶ「質問」を1つと、静かな日（新しい発表が無い日）の決まり |
| 4 | `prompts/plan_work.md` | どんな作業を試すと、読む人が「自分もやってみよう」と思うか |
| 5 | `prompts/generate_post.md` | 文章の形・1行目・使い方の書き方 |

あわせて **`settings.yml`**（Claude のモデル・動画に出すアカウント名・投稿の文字数・「ここは必ず見てほしい」集める先）も自分用にします。Claude に次の文を送ると、**最初に「プランは Pro ですか、Max ですか？」と聞かれ**、答えに合わせてモデルも設定されます。
```
settings.yml を、私の発信に合わせて書き換えたいです。上から1つずつ質問してください。
```

- 「ここは変えない」と書いてある部分は、仕組みが動くために必要なので残してください
- 「書き方の例」は、そのまま使わないでください（例です）

### 投稿したら記録する
同じ話題を続けて選ばないように、投稿したら `posted.json` に1行足します（Claude に「posted.json に今日の投稿『〇〇』を足して」と頼めばOK）。

## 毎日自動で動かす（使い慣れてから）

`.github/workflows/run.yml` の上のほうにある、次の3行の先頭の `#` を消します（Claude に頼んでもOK）。
```
#  schedule:
#    - cron: '0 21 * * *'
```
時刻は世界時間で書きます（日本時間から9時間引く）。例：`0 21 * * *` ＝ 日本時間の朝6時。
GitHub の予約は、混んでいると数十分〜数時間遅れることがあります。

## うまくいかないとき

Actions の実行結果のページで、**赤い ✗ が付いた段**をクリックすると、何が起きたかが出ます。

| 止まった段 | よくある原因 | 確かめること |
|---|---|---|
| ⓪③⑤⑦⑧（Claude の段） | Claude の鍵が無い・間違い／プランの使用量の上限／プランで使えないモデル | Secrets の名前が `CLAUDE_CODE_OAUTH_TOKEN` で正しいか。鍵を取り直して入れ直す。Claude の使用量に余裕があるか（上限に届いたら、時間をおいて動かす）。`settings.yml` の `claude` を `opus` にしていて止まるなら `sonnet` に戻す |
| ① 集める | 話題が0件 | `prompts/reader.md` を書く／`settings.yml` に集める先を書く |
| ⑩ ドライブに保存・メール | 受け取り係の設定 | `GAS_URL`・`GAS_KEY` の名前と値。受け取り係を「新しいデプロイ」でデプロイしたか（アクセスできるユーザー：全員） |
| ⑨ 動画を書き出す | 下書きの形が壊れている | もう一度動かす（AI の書き方が毎回少し違うため、2回目で通ることが多い） |

- 動画が作れなくても、投稿案の文章はメールで届きます
- 「試さない日」はパターン動画になります（失敗ではありません）
- ドライブやメールに届かなかったときも、Actions の実行結果のページのいちばん下（Artifacts）に「予備」として同じものが入っています（7日間）

## フォルダの中身（どこに何があるか）

| 場所 | 中身 | 書き換える？ |
|---|---|---|
| `prompts/reader.md`・`choose_topic.md`・`plan_work.md`・`generate_post.md` | AI が読む決まり | **はい**（冒頭の頼み方で） |
| `tonmana.md`・`examples/` | 口調とお手本 | **はい** |
| `settings.yml` | アカウント名・文字数・必ず見てほしい集める先 | **はい** |
| `posted.json` | 投稿済みの記録 | 投稿したら足す |
| `gas/受け取り係.gs` | Google ドライブとメールの係（Apps Script に貼る） | いいえ |
| `prompts/sources.md`・`explain_work.md`・`repair_post.md`・`validate_post.md`・`hallucination_rules.md` | 集める先を決める段・事実を守る段の決まり | いいえ（ふつうは） |
| `sns-studio/` | 動画とカルーセルを作る道具と、その形の決まり | いいえ（色を変えたいときは `src/brand.ts`） |
| `collect.py` ほか `.py` | 集める・並べる・照合する・届けるプログラム | いいえ |
| `.github/workflows/run.yml` | 動かす順番の手順書 | 毎日動かすときだけ |
