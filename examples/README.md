# お手本の投稿（examples/）

ここには、**あなたが「いいな」と思う投稿**を入れます。自分の投稿でも、ほかの人の投稿でもかまいません。

## 入れ方
- 1つの投稿を1つのファイルにして、このフォルダに入れます（例：`01.txt`、`02.txt` …）
- 本数は決まっていません。3本でも10本でもかまいません
- GitHub の画面なら：このフォルダを開いて「Add file」→「Create new file」→ 名前を `01.txt` にして、投稿の文をそのまま貼り付けて「Commit changes」

## 使い方
1. 集めたら、Claude に読ませて、**共通している書き方の特徴**を分析してもらいます
2. 分析した特徴を `tonmana.md`（口調の決まり）にまとめてもらいます（頼み方は tonmana.md の冒頭にあります）
3. 投稿を書く AI は、毎回このフォルダの投稿も読みます

## 大事な約束
- **真似るのは書き方だけ**です。お手本の中に書いてある事実（機能名・数字・出来事）は、あなたの投稿には使いません
- ほかの人の投稿を入れるときは、自分の手元の参考にとどめ、そのまま公開したり配ったりしないでください
