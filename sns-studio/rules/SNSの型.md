# SNSの型（動画・カルーセルの形の決まり）

動画（リール・TikTok・横長）とカルーセルの「形」の決まりです。中身の口調は `tonmana.md`、読む人は `prompts/reader.md` に従います。
ここは見た目と文字数の決まりなので、ふつうは書き換えなくて大丈夫です（文字数を超えると画面からはみ出します）。

---

## 1. 型（パターン）— 色・動き・音楽がまるごと変わる

最初に入っている型は3つだけです。**自分の発信に合う型は、Claude と話しながら足していきます**（`rules/型を自分で作る.md`）。

| pattern | 名前 | 選ぶとき | 主な場面（kind） | 最後のお願いの目安 |
|---|---|---|---|---|
| `howto` | ノウハウ | 手順・チェックリスト・やり方 | hook / chat / brief / flow / point | 保存＋フォロー |
| `naruhodo` | なるほど | 意外な事実・「へえ」が1つある | question / answer（`countdown: true`）/ chat | 送る＋保存 |
| `compare` | ビフォーアフター | 前と後で何が変わったか | hook / compare / chat / point | 保存＋フォロー |

- 自分で型を足したら、その型も選んでよい（`sns-studio/tools/sns_common.py` の PATTERNS にある型だけ使える）
- 長さは `beats`（拍の数）で書く。目安：hook 6／point 6〜7／chat・brief・flow 10／answer＋countdown 11／compare 9／todo 10／cta 6〜8（部品1個 8・2個 10・3個 12）
- 1本の中で同じ kind を3回続けない

### マーカー（mark）
- 各場面・各枚で、いちばん伝えたい言葉を1つ `mark` に書くと黄色のマーカーが引かれる
- mark は title / text / body の中に**そのまま含まれている言葉**にする

## 2. リール（縦 1080×1920・横長 1920×1080・TikTok も同じ中身）

- **7〜10場面・合計35〜45秒**（1場面 3〜5秒）
- 流れ：つかみ → 何が新しいか → しくみの絵 → 使う場面のビフォー→アフター → こう使える（2つ）→ 気をつけること（あれば）→ やることはこれ（todo）→ お願い（cta）
- 各場面に書くもの：`kind`／`text`／`sub`（任意）／`mark`／`beats`

| kind | 使いどころ | 文字数の目安 |
|---|---|---|
| `hook` | 1場面目 | text 3行まで・1行8字まで |
| `point` | 中身 | text 2行まで・1行9字まで、sub 1行16字まで |
| `list` | まとめ | text 1行9字、items 4個まで・1個10字まで |
| `question` / `answer` | なるほどの「？」と「！」 | text 2行まで・1行9字まで |
| `todo` | **cta の直前に必ず**：やることはこれ | text 2行・1行10字（任意）、`items` 1〜3手順・1つ12字まで、`say` 頼み方の言葉 2行・1行14字まで |
| `cta` | 最後 | text 2行まで・1行10字まで、`cta` に部品を1〜3個 |

### イメージ図の場面（文字だけの場面を続けない。7場面以下なら3つ以上・8場面以上なら4つ以上）
| kind | 図 | 書くもの |
|---|---|---|
| `chat` | チャット画面（右＝自分、左＝AI） | `"chat": {"me": "自分の一言", "attach": "添付ファイル名（任意）", "ai": "AI の返事", "aiMarks": ["返事の中で強調する言葉"], "note": "返事のあとの札（任意）"}` |
| `brief` | 1枚の紙に ✓ が順に入る | `"brief": {"title": "紙の題", "items": ["…"]}`（4個まで・1個10字まで） |
| `flow` | 手順が順に光る | `"steps": ["…"]`（4個まで・1個8字まで） |
| `punch` | 言葉が1語ずつ中央に飛び込む | `"words": ["…"]`（4語まで・1語7字まで） |
| `number` | 数字が数え上がる | `"value": "3"`／`"label": "…"`／`text` |
| `compare` | 上に BEFORE、下に AFTER | `"before": "…"`／`"after": "…"`（各2行・1行12字まで） |
| `cards` | カードが重なる | `"cards": ["…"]`（4枚まで・1枚8字まで） |

- イメージ図の場面の `text` は2行まで・1行10字まで
- `chat` の画面には「（イメージ）」と出る。実際の機能や返事を断定する内容にしない
- 公式ロゴは描かない（商標）
- 改行は `\n` で自分で入れる。`hook` / `point` は `"align": "center"` で中央寄せにできる。左寄せと中央の場面を混ぜる

### 最後のお願い（cta の部品）
| 部品 | 動き | 出る言葉（初期値） |
|---|---|---|
| `save` | しおりが黄色に塗られる | 保存して見返してね |
| `like` | ハートが赤くなる | 良いなと思ったらいいね |
| `follow` | 「フォロー」→「フォロー中 ✓」 | フォローで続きも届きます |
| `comment` | コメント欄に `keyword` が打たれる | コメントで教えてね（`commentLabel` で変更可） |
| `share` | 紙飛行機が飛ぶ | 知らない人に送ってあげてね |
| `profile` | プロフィールカードに「↑」 | ほかの投稿はプロフィールから（名前は settings.yml） |
| `line` | 緑のボタン | プロフィールのリンクから（`lineLabel`・`lineSub` で変更可。渡せる特典があるときだけ） |

- 渡せるものが無い約束（「コメントで送ればDMで届く」など）はしない

## 3. カルーセル（1080×1350・4〜8枚）

| type | 使いどころ | 書くもの | 文字数の目安 |
|---|---|---|---|
| `cover` | 1枚目 | kicker（英字・任意）／title（3行まで）／sub（任意）／mark | title 1行9字まで、sub 1行18字まで |
| `question` | なるほどの1枚目 | title（3行まで）／sub | 1行11字まで |
| `answer` | なるほどの2枚目 | title（3行まで）／body／mark | 1行11字まで |
| `point` | 中身 | no（"01"〜）／title（2行まで）／body（3行まで）／mark | title 1行10字まで、body 1行18字まで |
| `list` | まとめ | title（2行まで）／items（3〜5個） | items 1個14字まで |
| `todo` | 最後から2枚目 | title（任意）／items（1〜3手順）／say（頼み方の言葉・2行） | items 1つ13字まで |
| `cta` | 最後 | title／body | title 1行10字まで |

- 1枚に伝えることは1つだけ
- カルーセルは話題そのもの（何ができる・手順・場面）。試した記録（作業の細かい記録）は入れない

## 4. 文章（キャプション）
| 媒体 | 長さ | 形 |
|---|---|---|
| Instagram（リール） | 100〜300字＋ハッシュタグ3〜5個（1行に1つ） | 口調は tonmana.md |
| Instagram（カルーセル） | 300〜800字＋ハッシュタグ3〜5個 | リールで足りない情報をここで補ってよい。リンクは入れない |
| Threads | 500字まで・ハッシュタグ1つまで | X より会話っぽく、最後は問いかけ |
| TikTok | 1〜3行＋ハッシュタグ3〜5個 | 短い問いかけ |
