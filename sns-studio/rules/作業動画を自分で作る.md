# 作業動画を自分で作る（応用）

このテンプレートの動画は、最初は「パターン動画」（文字と図で話題を見せる動画）だけです。
慣れてきたら、**AI に話題の機能を本当に試させて、その様子を動画にする「作業動画」**を、Claude Code と話しながら自分で足していけます。

## 作業動画とは
- その日の話題（新しい機能など）を、GitHub の上で Claude Code に**本当にやらせてみる**
- やっている様子（頼んだ言葉・動き・できたもの）を記録して、それを画面にした動画を作る
- 「ニュースを紹介する」だけでなく「実際にやったらこうなった」を見せられるので、説得力が出ます

## 足す順番（1つずつ、動くのを確かめながら）
1. **計画**：選んだ話題を、どう試すかを AI が決める段
2. **試す**：GitHub の上で Claude Code に実際にやらせて、記録を残す段
3. **動画**：記録を画面にして書き出す段

一度に全部作らず、1つずつ足して、そのたびに1回動かして確かめます。

## Claude への頼み方（そのまま貼って送る）

Claude（デスクトップアプリの Code タブ、または claude.ai/code）でこのリポジトリを開いて、次の文を送ります。

```
この SNS 自動投稿の仕組みに、「作業動画」を足したいです。
作業動画とは、その日の話題の機能を GitHub の上で Claude Code に本当に試させて、その様子を動画にするものです。
まず、全体の作り方を、専門用語を使わずに説明してください。
そのあと、次の順番で、1つずつ作りたいです。1つ作るたびに止まって、私が GitHub で動かして確かめてから次へ進みます。
1. 計画の段：今日の話題を、どう試すか決める（試せない話題の日は、いつものパターン動画にする）
2. 試す段：GitHub の上で Claude Code に実際にやらせて、記録を残す
3. 動画の段：記録を、画面の様子が分かる動画にする（sns-studio の Remotion を使う）
先に prompts/reader.md・.github/workflows/run.yml・sns-studio/ を読んで、今の仕組みに合わせて提案してください。
ファイルを書き換える前に、変える内容を見せて確認させてください。
```

## 気をつけること
- 試させる作業は、**架空のサンプルデータ**で、数分で終わる小さなものにする（本物のお客さまの情報は使わない）
- 試せるのは、Claude Code で動かせる機能の話題のときだけ。ほかの会社の発表などは、パターン動画のままにする
- Claude Code に許す操作は、作業用のフォルダの中だけにする（Claude に「安全に動く範囲に絞って」と頼む）
- 動かすたびに Claude のプランの使用量と GitHub の時間を使います。試すのは1回ずつ
- 見た目は、ほかの人の作業動画をそのまま真似せず、自分の型にする
