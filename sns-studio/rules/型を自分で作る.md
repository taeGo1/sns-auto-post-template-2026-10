# 動画の型（パターン）を自分で作る

最初に入っている型は3つ（ノウハウ・なるほど・ビフォーアフター）だけです。
あなたの発信に合う型は、**Claude Code と話しながら、自分で足していきます**。色・動き・音楽・最後のお願いまで、あなたらしい型にできます。

## Claude への頼み方（そのまま貼って送る）

Claude（デスクトップアプリの Code タブ、または claude.ai/code）でこのリポジトリを開いて、次の文を送ります。

```
sns-studio に、私の発信に合う動画の型（パターン）を1つ足したいです。
先に prompts/reader.md と tonmana.md を読んでから、次のことを1つずつ質問してください。
・どんな話題のときに使う型か（例：お得情報、新機能の紹介、使い方の手順）
・見た目の雰囲気（色・明るさ・かわいい／かっこいい など）
・動き（ゆったり／テンポよく）と音楽の速さ
・最後のお願い（保存・フォロー・コメントなど）
決まったら、次のファイルを書き換えてください。
・sns-studio/src/brand.ts の THEMES に新しい型を足す（色は brand.ts の C を使うか、新しい色を足す）
・sns-studio/tools/sns_common.py の PATTERNS と PATTERN_BPM に同じ名前を足す
・sns-studio/rules/SNSの型.md の型の表に1行足す（選ぶとき・主な場面・最後のお願い）
書き換える前に、変える内容を見せて確認させてください。
```

## 色だけ変えたいとき
```
sns-studio/src/brand.ts の色（C）を、私のブランドカラー〇〇（例：#FF8FA3 のピンク）に合わせて変えたいです。
文字が読みやすいかも気をつけて、変える前に案を見せてください。
```

## 足したあとに確かめること
- GitHub の Actions で1回動かして、新しい型の動画が届くか見る（AI は、話題に合えば新しい型を選びます）
- 見た目が気に入らなければ、届いた動画を見ながら「〇〇をもう少し△△に」と Claude に頼んで直す

## 注意
- 型の名前は英小文字（例：`otoku`、`tips`）
- ほかの人の動画の見た目をそのまま真似しない（雰囲気を参考にして、自分の型にする）
